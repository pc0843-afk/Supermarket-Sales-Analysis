# Supermarket Sales Analysis & Business Insights

**Program:** Data Analytics with AI Internship Program 2026  
**Project Topic:** Supermarket Sales Analysis & Business Insights  
**Domain:** Data Analytics with AI

## Objective
Analyze supermarket transaction data to identify sales patterns across product lines, branches, gender and payment methods, and present the results using KPIs and visualizations.

## Technologies
Python, Pandas, NumPy, Matplotlib, Seaborn.

## Files
- `supermarket_sales_analysis.py` — main analysis code
- `supermarket_sales.csv` — self-contained practice dataset
- `requirements.txt` — Python dependencies
- `Project_Report.pdf` — project report
- `outputs/` — generated CSV summaries, chart images and insights

## Run
```bash
pip install -r requirements.txt
python supermarket_sales_analysis.py
```

## Workflow
Data loading → data inspection/cleaning → KPI calculation → grouped analysis → visualization → business insights.

## Note
The included CSV is a small self-contained practice dataset prepared to demonstrate the analytics workflow. If the internship provides an official dataset/workbook that must be used, replace the CSV with that official data before final submission.
